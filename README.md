# ♡ Vida Greens

Static site for **Vida Greens (LoveVida)** — small-batch, plant-based smoothies in clear 16 oz zipper pouches. Huntington Park, CA. Pickup & shipping.

## Open in the browser (no npm)

```bash
git fetch origin
git checkout cursor/huerta-juicery-website-9917
```

Open **`index.html`** in Chrome (double-click).
